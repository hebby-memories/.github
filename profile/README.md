### 🧠 What Hebby does

Hebby is a second brain for your AI agents. It keeps your projects, decisions and lessons learned, and brings in exactly what fits, before you have to explain it again.

- **One memory for all your agents.** Claude Code, Codex, ChatGPT, Hermes and Paperclip work on the same memory at the same time. What one learns, all know.
- **Graph memory, not loose notes.** Projects, people, systems and decisions are linked. Hebby finds what *belongs* together, not just what *sounds* similar.
- **Anticipation.** Hebby notices where your work is heading and brings the next fact in before your agent asks.
- **Learns in its sleep.** Every night it condenses, sorts and consolidates. Outdated knowledge fades, what matters stays.
- **No more CLAUDE.md upkeep.** No memory files to maintain. Hebby remembers on its own.
- **Permissions and secret guard.** You decide which agent and which person sees which topic. Secrets are rejected before they are stored.

### 🔬 Built on how memory really works

| Principle | What it means for your agent |
|---|---|
| **Hebbian learning** | What is used together gets linked more strongly, like neurons that fire together. |
| **Associative anticipation** | Knowledge is activated before it is needed. |
| **Consolidation** | Nightly condensing, like the brain during sleep: sharper hits, fewer tokens. |
| **Targeted forgetting** | Stale knowledge steps back, so the memory stays current. |
