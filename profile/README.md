### Hebby Memories

Long-term memory for AI agents, based on how human memory works: Hebbian learning, consolidation, forgetting.

<br clear="left">

- **Works with:** Claude Code, Codex, ChatGPT, Hermes, Paperclip and any MCP client
- **Benchmark:** #1 on [PrecisionMemBench](https://www.hebby-memories.com/en/benchmarks/) among systems that didn't write the benchmark (28/43 precision tasks)
- **Cost:** about 5 % token overhead, measured over 217,000 API calls ([details](https://www.hebby-memories.com/en/token-efficiency/))
- **Hosted or self-hosted**
- **MCP Registry:** `com.hebby-memories/hebby`
